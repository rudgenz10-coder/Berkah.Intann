Data & backup

Backup data

Simpan seluruh data (produk, restok, penjualan) ke satu file. Data aplikasi ini tersimpan di browser, jadi hilang kalau data browser dihapus. Simpan file backup di tempat aman.

Pulihkan dari backup

Pilih file backup yang pernah diunduh. Semua data saat ini akan diganti. Sebelum mengganti, backup data saat ini diunduh otomatis sebagai pengaman.

Ekspor ke Excel

Satu file .xlsx berisi 5 sheet: Ringkasan, Penjualan, Item Penjualan, Produk, dan Restok. Bisa dibuka di Excel, Google Sheets, atau WPS.
